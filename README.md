# InterviewBar Windows · 秋招面板

面向 Windows 10/11 的本地秋招日程与投递面板。它把面试、笔试、测评和 AI 面试放进同一份日程，支持手动录入、招聘邮件字段识别、本地投递表以及按周回顾。

> **Windows 重写修改版**
>
> 本项目参考 [byp411426/InterviewBar_MacOS](https://github.com/byp411426/InterviewBar_MacOS) 的功能、交互和数据语义，基于原项目 `v0.10.2`、提交 `638f4d8110f49c4bd602dab0ca73135483b3f104`，使用 Electron、React 与 TypeScript 为 Windows 重新实现。它不是原版 Swift 程序的直接编译版本，原作者未为本修改版提供担保或背书。

## 当前功能

- Windows 通知区域托盘：打开/隐藏主面板、添加安排、读取剪贴板进入邮件识别、打开投递表与统计、退出应用；托盘提示显示下一项未来安排。
- 今日面板：下一项倒计时、未来待办、过期待确认、时间待通知、累计完成与投递记录概览。
- 日程管理：添加、编辑、删除、搜索和筛选面试、笔试、测评、AI 面试；状态包括待进行、已完成、已取消和未通过。
- 四种时间完整度：具体时间、仅有日期、从某日起陆续安排、日期时间均待通知。
- 邮件识别：主动粘贴或读取剪贴板，使用本机规则或自配 AI 服务提取字段；并排核对后才写入日程与投递记录。
- 投递工作台：本地投递表、日程明细和飞书原表入口；支持 CSV/TSV 导入、搜索、筛选、排序、详情查看和日程 CSV 导出。
- 秋招之旅：近 8 周、近 12 周或全部时间的分类柱状图、累计趋势和周记录明细，可切换“已完成”与“全部安排”口径。
- Windows 集成：登录后自动启动、浅色/深色主题、本机通知、系统浏览器打开链接、本机数据目录入口。
- 本地持久化：JSON 原子写入、上一版自动备份、损坏时尝试读取备份；AI 密钥与业务数据分开保存。

## 重要数据语义

- 所有日程日期和时刻按 `Asia/Shanghai`（北京时间）解释，并以分开的 `YYYY-MM-DD`、`HH:mm` 字段保存。
- 只有日期或“陆续安排”的通知不会被补成 `00:00`，不会进入周统计，也不会安排定时提醒。
- 时间过去不会自动删除记录，也不会自动标记完成；它仍是“时间已过 · 待确认”。
- “下一项”只从未来、待进行且时间完整的记录中选择。
- “已完成”统计只计算用户手动标记为已完成的记录。“全部安排”还包含待办、取消和未通过，不代表实际参加次数。
- 周统计按北京时间周一至周日归档。近 8/12 周截至本周；“全部时间”可包含未来周。
- 提醒可设为不提醒、提前 5/15/30/60 分钟或 1 天。提醒仅是辅助，不能替代招聘方通知和其他重要日历提醒。

## Windows 安装

当前打包配置面向 **Windows 10/11 x64**，生成 NSIS 安装包和便携版。ARM64、32 位 Windows 尚未配置或验证。

1. 从可信来源取得构建产物，并核对来源和校验值。
2. 安装版运行 `release/InterviewBar-Windows-<版本>-x64-Setup.exe`，按向导选择安装目录；便携版 `release/InterviewBar-Windows-<版本>-x64-Portable.exe` 可直接运行。
3. 首次启动后，应用会显示主窗口，并在任务栏通知区域创建托盘图标。
4. 点击窗口关闭按钮只会隐藏窗口，应用仍在托盘运行。要完全结束进程，请使用托盘菜单“退出”或设置页“退出应用”。

当前仓库没有配置 Windows 代码签名证书。自行构建的安装包或便携版可能触发 Microsoft Defender SmartScreen 提示；这不等同于签名或信誉校验已经完成。只应运行来源可核验的构建产物。

## 从源码运行

需要 Windows 10/11 x64、Git、Node.js 和 npm。当前开发环境使用 Node.js 24 与 npm 11；建议使用与 `package-lock.json` 兼容的 Node.js 版本。

```powershell
cd D:\path\to\InterviewBar
npm ci
npm run dev
```

`npm run dev` 会同时启动仅监听本机的 Vite 开发服务器和 Electron。开发模式下打开的是完整桌面应用。

常用检查与构建命令：

```powershell
npm run typecheck
npm test
npm run build
npm run dist
```

| 命令 | 作用 |
| --- | --- |
| `npm run typecheck` | 检查渲染层和 Electron 主进程 TypeScript |
| `npm test` | 运行领域层 Vitest 测试 |
| `npm run build` | 检查类型、运行测试，并生成 `dist/` 与 `dist-electron/` |
| `npm run dist` | 完整构建后使用 electron-builder 生成 Windows x64 NSIS 与便携版，输出到 `release/` |
| `npm run preview` | 仅预览已构建的网页渲染层，不等同于 Electron 桌面应用 |

浏览器预览使用 `localStorage` 和浏览器文件选择回退，不提供托盘、Windows 加密凭据、登录自启、原生通知或 Electron 文件对话框，不能用于验收这些桌面能力。

## 基本使用

### 手动安排

点击“添加安排”，填写公司、岗位、类型、状态和时间。只有公司为必填项；链接必须是完整 HTTP/HTTPS 地址。若招聘方没有给出具体时刻，请选择“只有日期”“从该日起陆续安排”或“日期与时间待通知”，不要自行填入午夜。

### 从招聘邮件识别

1. 在邮箱中只复制本次通知相关的正文。
2. 打开“识别邮件”，点击粘贴剪贴板，或在原文框中按 `Ctrl+V`。
3. 选择“本机规则”或“AI 识别”。本机规则不发送网络请求。
4. 核对公司、岗位、类型、轮次、日期、时刻、时间含义、地点和参加链接。
5. 选择新增或更新的日程与投递记录，再确认保存。

同一正文会按 SHA-256 摘要提示重复导入。原文中的“拒绝、放弃、推迟、退订”链接不会作为参加入口。任何识别结果都可能出错，日期、时区和链接最终以招聘方原文为准。

### AI 服务

AI 是可选功能。不配置时仍可手动录入或使用本机规则。当前提供 DeepSeek、千问/百炼、Kimi、GLM/智谱预设和自定义 OpenAI Chat Completions 兼容 HTTPS 服务。预设不保证模型长期可用、账户权限、速度或价格。

在“设置 → AI 服务 → 配置与用量”中填写 API 地址、模型和自己的密钥。API 地址必须使用 HTTPS，且不能包含账号、密码、查询参数或 URL 片段。连接测试发送固定的虚构招聘通知，会产生少量 Token；若测试时输入了新密钥，当前桌面实现会先加密保存该密钥再发起测试。

只有用户在邮件识别页主动执行 AI 识别时，当前邮件正文才会发送到所配置的模型服务。详细数据处理方式见 [数据与隐私](docs/PRIVACY.md)。

### 投递表与 CSV

- 桌面版可导入不超过 20 MB 的 UTF-8、UTF-16 CSV/TSV；第一行必须是唯一、非空列名，并包含“公司”“公司名称”“企业”或 `company` 列。
- 导入替换本机的投递表快照，不修改日程、在线飞书或原始 CSV/TSV 文件。
- 日程导出为带 UTF-8 BOM 的 CSV，包含日程和投递结果。为降低表格公式注入风险，以可选空白加 `= + - @` 开头的用户字段会自动加单引号。
- CSV 导出不是完整备份：它不包含全部设置、导入摘要、AI 用量、原始投递表结构或加密凭据。

### 飞书原表

工作台可保存飞书/LarkSuite 或其他 HTTPS 表格地址，并交给系统默认浏览器打开。应用不会嵌入登录页面，也不会读取网页内容。

**在线飞书与本地数据不会自动同步。** 浏览器中编辑只影响在线原表；本机导入、日程修改和邮件识别不会自动回写飞书。

## 数据目录与备份

桌面版优先使用：

```text
%LOCALAPPDATA%\InterviewBar
```

若 `LOCALAPPDATA` 不可用，则回退到 Electron 提供的 Windows 应用数据目录下的 `InterviewBar`。可在“设置 → 数据与隐私 → 打开数据目录”直接定位。

| 文件 | 内容 |
| --- | --- |
| `app-data.json` | 日程、投递记录、本地表格快照、设置、导入摘要和 AI 用量元数据 |
| `app-data.json.backup` | 每次成功保存前复制的上一版主数据文件 |
| `credentials.json` | 使用 Electron `safeStorage` 加密后的模型密钥，不含明文密钥 |

完整备份步骤：先从托盘或设置页退出应用，再复制整个 `InterviewBar` 数据目录。恢复前同样完全退出应用，先把当前目录另存一份，再替换需要恢复的文件。

`credentials.json` 的密文绑定 Windows 的安全存储环境，复制到另一台电脑或另一个 Windows 用户后不保证能解密；迁移时通常需要重新保存 API 密钥。业务 JSON 与其自动备份是明文文件，应像招聘邮件一样妥善保护。

## 当前限制

- 仅配置并验证 Windows x64 构建；没有 ARM64 或 32 位发行目标。
- 没有 Windows 代码签名、发布者证书、自动更新或安装包信誉保证。
- 没有浏览器扩展或 Windows Native Messaging Host；需手动复制邮件正文。本仓库没有声称兼容 macOS 版 Chrome 扩展。
- 没有 Windows 系统 Widget，也没有桌面悬浮组件。
- 不登录邮箱、不做 IMAP/全邮箱监控、不持续监听剪贴板、不做截图 OCR。
- 不提供云端账户、跨设备同步或飞书双向同步。
- AI 仅支持当前实现的 OpenAI Chat Completions 风格响应；兼容服务仍可能因字段、鉴权或模型行为差异失败。
- AI 本机复用缓存只存在于当前进程内，最多 20 条、约 10 分钟；退出应用即消失。
- 通知要求应用仍在运行、系统支持通知且提醒时刻尚未错过；最多调度最近 60 条。Windows 通知权限、专注助手、休眠、注销和关机都会影响送达，应用不会保证必达或补发已错过提醒。
- 便携版移动路径后，登录自启项可能失效，需要重新设置。
- 当前“秋招之旅”内置的是精简版本地鼓励语，不等同于参考项目的全部内容。
