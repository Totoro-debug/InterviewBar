# 数据与隐私

本文说明 InterviewBar Windows 当前源码如何处理招聘记录、邮件正文、模型密钥、用量信息和外部链接。它描述的是这个 Windows 重写修改版，不代表模型服务商、飞书、浏览器或 Windows 本身的隐私政策。

## 一览

| 数据 | 默认保存位置 | 是否离开本机 |
| --- | --- | --- |
| 日程、投递记录、表格快照、设置 | `%LOCALAPPDATA%\InterviewBar\app-data.json` | 应用自身不会上传 |
| 上一版业务数据 | `app-data.json.backup` | 应用自身不会上传 |
| API 密钥 | 经 Electron `safeStorage` 加密后写入 `credentials.json` | 调用模型时作为 HTTPS Bearer 凭据发送给配置的服务 |
| 邮件原文 | 识别窗口的临时内存状态 | 本机规则不发送；主动 AI 识别时发送给配置的服务 |
| 导入历史 | 正文 SHA-256 摘要和导入时间，写入 `app-data.json` | 应用自身不会上传 |
| AI 用量 | 调用元数据，写入 `app-data.json` | 服务商会按自己的规则记录其收到的请求 |
| 飞书表格 | 本机只保存 URL | 在系统浏览器打开后，由浏览器和飞书处理 |

本项目当前没有开发者运营的账户系统、遥测端点或数据同步服务器。

## 本机业务数据

`app-data.json` 包含：

- 公司、岗位、安排类型、轮次、日期、时刻、状态、地点、链接、备注和提醒设置；
- 投递记录和导入的本地表格快照；
- 飞书或其他 HTTPS 表格地址；
- 应用主题、自启动、通知和模型配置，但不含 API 密钥；
- 邮件正文摘要与导入时间；
- AI 调用用量元数据。

这些 JSON 文件不是加密数据库。能够读取当前 Windows 用户文件的人员或软件，也可能读取其中的招聘信息、会议链接和备注。`app-data.json.backup` 同样是明文。建议使用 Windows 登录保护和设备加密，并谨慎备份。

保存时先保留上一版 `app-data.json.backup`，再以临时文件和重命名方式更新主文件。主文件读取失败时，应用会尝试读取备份；两者都不会因解析失败而被自动清空。自动备份只有一代，不能代替用户自己的版本化备份。

## 剪贴板与邮件正文

应用不持续监听剪贴板。只有以下操作会读取当前文本：

- 用户在邮件识别页点击粘贴；
- 用户点击托盘菜单“粘贴识别邮件”。

本机规则在渲染进程中解析正文，不发起网络请求。邮件原文不会写入 `app-data.json`；确认导入后只保存用户核对过的结构化字段、确认备注、正文 SHA-256 摘要和导入时间。关闭应用后，AI 本机复用缓存和识别窗口中的正文会从进程内存中消失。

如果用户主动选择 AI 识别，当前正文会作为请求内容发送到自己配置的模型 HTTPS 地址。请求还包含字段提取提示、模型名和作为日历参考的北京时间日期。应用提示模型把邮件当作数据而非指令，但不能保证第三方模型永远正确处理恶意或异常正文。

不要粘贴与本次招聘通知无关的邮件线程、签名、身份证号、手机号或私人聊天内容。

## API 密钥

API 密钥不会写入 `app-data.json`。桌面主进程使用 Electron `safeStorage` 调用 Windows 提供的加密能力，再把密文存入：

```text
%LOCALAPPDATA%\InterviewBar\credentials.json
```

模型配置按规范化后的 API 端点区分凭据。渲染页面只能通过受限 IPC 查询“是否已保存”、提交新密钥或发起识别，不能直接读取明文密钥。真正的 HTTPS 请求由 Electron 主进程发出。

需要注意：

- 密文通常只应在相同 Windows 安全上下文中解密；复制到另一设备或用户后不保证可用。
- Windows 安全存储不可用时，应用拒绝保存或读取密钥，不会回退到明文。
- 输入新密钥并执行“测试连接”时，当前实现会先加密保存密钥，再发送固定测试请求。
- 当前界面没有单个凭据的删除按钮。要移除全部已保存模型密钥，可完全退出应用，备份后删除 `credentials.json`；下次保存时会重新创建。

不要把 `credentials.json`、API 密钥、带鉴权查询参数的链接或服务商控制台截图提交到 Issue。

## AI 网络请求与用量

模型地址必须是 HTTPS，且不能内嵌账号、密码、查询参数或 URL 片段。应用不跟随模型接口的 HTTP 跳转。正文上限为 60 KB，单次响应上限为 500 KB，请求超时为 75 秒。

“测试连接”只发送固定的虚构招聘通知，不发送剪贴板或当前邮件正文，但可能产生少量 Token 和服务商费用。

每次调用最多在本机保留以下用量元数据，共 10,000 条：

- 请求时间、用途、服务商、模型和耗时；
- HTTP 状态、成功/失败和简化错误信息；
- 服务商实际返回的输入、输出和缓存输入 Token；
- 是否复用了本机缓存。

用量记录不包含邮件正文或 API 密钥。服务商未返回 Token 时显示“未提供”，不会按字数估算或当作零；应用不估算金额，以服务商账单为准。

相同正文和配置的快速 AI 结果可在当前进程内复用，缓存上限 20 条、有效期约 10 分钟。缓存键包含正文的 SHA-256 派生值，缓存值是解析后的字段；缓存不写磁盘，点击重新识别会跳过复用。

第三方模型服务会依据其自己的条款处理请求、密钥、日志和计费。使用前应确认服务商的数据保留、训练使用、地域和企业合规政策。

## CSV、飞书与外部链接

CSV/TSV 导入只读取用户在文件对话框中选择的单个本地文件。桌面版限制为 20 MB。导入保存一份本地表格快照，不会修改原文件或在线表格。

CSV 导出会把业务字段写入用户选择的位置。为降低电子表格公式注入风险，以可选空白加 `= + - @` 开头的用户字段会加前导单引号；所有字段还会用双引号包围并转义内部引号。这是风险缓解措施，不是对所有表格软件行为的绝对保证，打开不可信 CSV 时仍应保持谨慎。

飞书原表页面只保存经校验的 HTTPS URL，再调用系统默认浏览器。应用不会嵌入飞书登录、读取网页、抓取 Cookie 或自动同步内容。其他会议、测评和招聘链接也通过系统浏览器打开；主进程只允许不含账号密码的 HTTP/HTTPS URL。

## Windows 通知

启用本机提醒后，通知可能显示公司、安排类型、日期、时刻和地点。这些内容可能出现在 Windows 通知中心或锁屏上，具体取决于系统隐私设置。共用电脑或投屏环境下，应在应用或 Windows 设置中关闭通知预览。

通知只对未来、待进行、具体时间已知且提醒值大于零的记录调度，最多保留最近 60 条。专注助手、通知权限、睡眠、注销、关机或应用未运行都可能导致延迟或丢失；已经错过的提醒不会保证补发。

## 删除与备份

删除单条日程会从下一次保存的主数据中移除。由于自动备份保存的是上一版，删除内容可能暂时仍存在于 `app-data.json.backup` 和用户自己的备份中。

要清除本机数据：

1. 从托盘菜单或设置页完全退出应用；仅关闭窗口不会结束进程。
2. 备份需要保留的数据。
3. 删除 `%LOCALAPPDATA%\InterviewBar` 中相应文件，或删除整个目录以清除该用户下的所有应用数据和密文凭据。

此操作不可由应用撤销。重新打开后会创建空白业务数据；模型密钥需要重新配置。
